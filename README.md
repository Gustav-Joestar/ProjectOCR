# ProjectOCR

## OCR-система распознавания инженерных чертежей и основных надписей

ProjectOCR --- программный комплекс для автоматизированного анализа
технической документации.

Назначение проекта: - поиск областей чертежей; - выделение основной
надписи (штампа); - распознавание текста; - исправление ошибок OCR; -
сохранение результата в структурированном XML-формате.

------------------------------------------------------------------------

# Возможности

## Поддерживаемые входные данные

Система работает с:

-   PDF-документами;
-   изображениями чертежей.

Поддерживаемые форматы:

    .png
    .jpg
    .jpeg
    .bmp
    .tif
    .tiff
    .webp

------------------------------------------------------------------------

## Основные функции

### Обнаружение чертежей

Для поиска областей документа используется YOLO-модель.

### Распознавание штампа

Pipeline выполняет:

1.  выделение области штампа;
2.  сегментацию ячеек;
3.  фильтрацию пустых областей;
4.  разделение текста на строки;
5.  OCR распознавание.

### Исправление OCR-ошибок

После распознавания применяется пользовательский словарь исправлений.

### Экспорт

Результат сохраняется в XML.

# Словарь исправлений OCR

Файл:

    dictionaries/ocr_corrections.csv

Формат:

``` csv
wrong,correct,type,enabled
```

Типы правил:

## exact

Используется для полного совпадения строки.

Пример:

``` csv
Ст3,Ст3,exact,1
```

## substring

Используется для исправления фрагмента внутри строки.

Пример:

До:

    C415 ГОСТ 1412-85

Правило:

``` csv
wrong,correct,type,enabled
C415,СЧ15,substring,1
```

После:

    СЧ15 ГОСТ 1412-85
