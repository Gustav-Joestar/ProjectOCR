# ProjectOCR

## OCR-система распознавания инженерных чертежей и основных надписей

ProjectOCR --- программный комплекс для автоматизированного анализа
технической документации.

Основная задача проекта --- извлечение информации из чертежей: - поиск
областей чертежей; - поиск основной надписи (штампа); - распознавание
текста; - исправление ошибок OCR; - сохранение структурированных данных.

# Возможности

## Поддерживаемые входные данные

Система принимает:

-   PDF-документы;
-   изображения чертежей.

Поддерживаемые форматы изображений:

    .png
    .jpg
    .jpeg
    .bmp
    .tif
    .tiff
    .webp

------------------------------------------------------------------------

## Основные функции

### Обнаружение чертежей

Используется модель компьютерного зрения YOLO.

Задача: - найти чертёж на странице; - выделить область обработки.

------------------------------------------------------------------------

### Извлечение основной надписи

После выделения чертежа система:

1.  ищет область штампа;
2.  выделяет поля;
3.  передаёт их в OCR.

------------------------------------------------------------------------

### OCR распознавание

Для распознавания текста используется PaddleOCR.

Распознаются поля основной надписи:

-   обозначение;
-   наименование;
-   материал;
-   масса;
-   масштаб;
-   лист;
-   разработчик;
-   проверяющий;
-   дата;
-   другие поля.

------------------------------------------------------------------------

### Исправление OCR-ошибок

После распознавания применяется пользовательский словарь.

Пример:

OCR:

    Hacoc шестеренный

После коррекции:

    Насос шестеренный

------------------------------------------------------------------------

### Экспорт

Результат сохраняется в XML.

# Требования

Рекомендуемая версия Python:

    Python 3.11

Почему Python 3.11:

-   хорошая совместимость с PyTorch;
-   стабильная работа PaddleOCR;
-   меньше проблем с зависимостями.

Запустить:

    install.bat

1.  создаёт виртуальное окружение;
2.  активирует его;
3.  устанавливает зависимости из requirements.txt.

Создание окружения:

``` bash
python -m venv venv
```

``` bash

```

``` bash
pip install -r requirements.txt
```

# Модели

------------------------------------------------------------------------

# Словарь исправлений OCR

Файл:

    dictionaries/ocr_corrections.csv

Формат:

``` csv
wrong,correct,type,enabled
```

Пример:

``` csv
Hacoc,Насос,substring,1
Шайда,Шайба,substring,1
```

------------------------------------------------------------------------

## Типы правил

### exact

Полное совпадение строки.

Пример:

    Ст3

исправляется только если вся строка совпадает.

------------------------------------------------------------------------

### substring

Поиск внутри строки.

Пример:

До:

    Hacoc шестеренный

После:

    Насос шестеренный

# Типовые ошибки

## cv2 не найден

Ошибка:

    ModuleNotFoundError: No module named 'cv2'

Решение:

    pip install opencv-contrib-python

------------------------------------------------------------------------

## PaddleOCR не установлен

Ошибка:

    No module named 'paddleocr'

Решение:

    pip install paddleocr paddlepaddle

------------------------------------------------------------------------

## Torch / CUDA ошибки

Рекомендуется:

-   использовать Python 3.11;
-   ставить совместимые версии PyTorch;
-   проверять наличие драйверов NVIDIA.
